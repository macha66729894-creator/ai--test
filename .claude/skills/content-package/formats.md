# 채널별 규격과 틀

길이 기준은 작성자 판단이며, 실제 성과를 보고 조정한다. 근거가 있는 항목은 출처를 적었다.

## 1. 릴스·쇼츠 대본

- 길이: 15~30초.
- **예상 길이를 반드시 적는다.** 대사의 음절 수를 세고 1초에 4~5음절로 나눠 추정한다. 이 속도는 경험칙이라 정확하지 않다. 실제 음성을 만든 뒤 실측 길이로 다시 확인해야 한다고 대본 끝에 적는다.
- 구성
  1. 0~3초: 타깃의 속마음 또는 반론으로 시작
  2. 기준점: 직접 하는 수고나 비교 대상
  3. 화면으로 증명: 넣는 장면, 뜨는 장면
  4. 쓰임새 1~2개
  5. 행동 하나
- 함께 쓸 것: 컷별 화면 설명, 자막, 캡션, 제목 후보 5개.
- 캡션은 대본과 같은 메시지를 반복한다.

## 2. 카드뉴스 (인스타 캐러셀)

- 4~5장. 장마다 문장 하나, 20자 안팎.
- 1장: 질문 또는 속마음. 2~4장: 장면 하나씩. 마지막 장: 제품 사진, "국·찌개·요리에, 250g", 행동 하나.
- 장마다 필요한 사진을 적는다. 보유 소재에 없으면 "촬영 필요"라고 적는다.
- 캡션 포함.

## 3. 스레드

- 서로 다른 각도로 3안. 한 안은 1~3줄.
- 판매 링크는 본문이 아니라 답글에 둔다.
- 각 안에 어울리는 사진 1장을 적는다.

## 4. 블로그

- 600~900자. 제목 후보 3개, 소제목 3~4개.
- 순서: 상황 → 흔한 해결법과 불편 → 대안 → 쓰는 법 2~3가지 → 구매 안내.
- 검색어 1개를 정해 제목과 첫 문단에 넣는다.

## 5. 뉴스레터

- 제목 후보 3개 (20자 이내), 미리보기 문구 1개.
- 본문 300자 안팎. 이야기 하나와 행동 하나.

## 출처

1. 릴스 구성 5단계: Notion "오퍼형 광고 대본 공통 구조 + 매콤찬 대본 3편"의 7단계를 줄였다.
2. 예상 길이 필수: Notion "2026-11-10 전사 업무 정리". 설계 26초와 실제 음성 13.75초가 달라 재승인을 받은 사고에서 가져왔다.
3. 대본과 캡션 일치: 같은 기록의 캡션 누락 사고.
4. 스레드 링크는 답글에, 카드뉴스 마지막 장 구성: Notion "X팀 콘텐츠 방향 초안 (2026-11-05)".
5. 글자 수와 장 수, 낭독 속도: 작성자 판단.
