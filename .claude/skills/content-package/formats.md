# 채널별 규격과 틀 (v2)

구조는 `references.md`의 조립 공식(H 훅 → B 장벽 → P 증거 → U 사용 연결 → O 제안 → A 행동)을 따른다. 길이와 글자 수는 작성자 판단이며 성과를 보고 조정한다.

## 공통

1. 소재마다 설계표 9칸을 먼저 채운다: 타깃 / 상황 / 구매 장벽 / 핵심 약속 / 증거 / 설득 유형(F1~F8) / 표현 방식 / 행동 목적 / 확인 상태.
2. 훅은 서로 다른 장치 3개를 만든다. 장치 예: 식사 상황 질문, 취향 양자택일, 정체를 숨긴 전후 변화, 반론 선점, 구체적 장면. 하나만 고르지 않고 비교할 수 있게 낸다.
3. 숨긴 것(정체, 결과)은 본문에서 반드시 공개한다.
4. 행동 유도는 하나다. 레시피는 저장, 취향 질문은 댓글, 상품 안내는 링크, 다음 이야기는 팔로우.
5. 아직 확인되지 않은 것은 `[촬영 후 확인]`, `[사용량 확인]`, `[가격]`처럼 표시한다.

## 1. 릴스·쇼츠 대본

- 길이: 15~30초.
- 예상 길이를 반드시 적는다. 대사의 한글 음절 수를 세어 1초에 4~5음절로 나눈다. 이 속도는 경험칙이라 오차가 크다. 음성을 만든 뒤 실측 길이로 다시 확인하라고 대본 끝에 적는다. (11/10 사고: 설계 26초, 실제 음성 13.75초)
- 첫 3초는 훅 컷 유형(`references.md` 3번)에서 하나를 고른다. A 제품에서 푹 뜨기, B 찌개·국물에 넣기, C 볶음에 푹 떠 넣기, D 밥 비비기. 썰기·손질 컷은 훅에 쓰지 않는다. 핵심 동작이 이미 진행 중인 상태로 시작한다.
- 구성
  1. 0~3초: H 훅 (상황, 질문, 반론, 사용 장면)
  2. B 장벽 한 줄
  3. P+U: 증거 장면과 사용 장면
  4. 쓰임새 확장 한 줄
  5. A 행동 하나
- 함께 쓸 것: 컷별 화면과 자막, 캡션(대본과 같은 메시지), 제목 후보 5개, 훅 3안.
- 제목 후보는 `references.md` 4번 패턴에서 가져오되, 정체를 숨기면 본문에서 공개한다.

## 2. 카드뉴스 (인스타 캐러셀)

- 5장. 질문 → 공감 → 근거 → 사용법 또는 선택 기준 → 행동.
- 장마다 문장 하나, 20자 안팎. 모바일에서 읽히는 크기를 기준으로 한다.
- 장마다 필요한 사진을 적고, 보유하지 않은 사진은 "촬영 필요"라고 적는다.
- 1장과 캡션 첫 줄은 같은 메시지다.
- 캡션 포함.

## 3. 스레드

- 서로 다른 장치로 3안. 한 안은 1~3줄.
- 양자택일이나 질문을 쓰면 다음 날 실제 댓글 수만 세어 결과 글을 쓴다는 계획을 적는다.
- 판매 링크는 본문이 아니라 답글에 둔다.
- 각 안에 어울리는 사진 1장을 적는다.

## 4. 블로그

- 600~900자. 제목 후보 3개, 소제목 3~4개.
- 순서: 상황 → 흔한 방법과 불편 → 대안 → 사용법 → 구매 안내.
- 검색어 1개를 제목과 첫 문단에 넣는다.
- 사용량과 맛 변화는 촬영·조리 확인 전에는 확정해서 쓰지 않는다.

## 5. 뉴스레터

- 제목 후보 3개(20자 이내), 미리보기 문구 1개.
- 본문 300자 안팎. 이야기 하나와 행동 하나.

## 6. 측정 계획 (패키지마다 한 줄씩)

- 목적이 클릭이면 링크 CTR(링크 클릭 ÷ 노출)과 CPC.
- 목적이 구매면 구매전환율과 CPA.
- 목적이 팔로우면 팔로우 수.
- 훅 3안은 같은 구매 경로에서 비교하고, 데이터가 적으면 "판단 보류"로 적는다. 조회수가 높다는 이유로 구매 성과가 좋다고 결론내리지 않는다.
