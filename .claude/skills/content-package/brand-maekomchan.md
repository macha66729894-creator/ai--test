## 확인 필요 (대표님 확인 전에는 쓰지 않음)

1. "강원도 청양고추만 사용": 기존 대본에 쓰였으나 원산지 표기 확인이 필요하다.
2. "저염", "방부제 무첨가": 표시·광고 규정 확인이 필요하다. 상세페이지에 이미 쓰는 표현 수준까지만 쓴다.
3. 가격, 할인율, 판매량, 행사 기간: 항상 `[ ]`로 비운다.
4. 표고다짐, 멸치볶음, 진미매콤찬의 현재 판매 여부와 상품 링크.
5. 고객 호칭 "치니들": 과거 메모에 한 번 나온 표현이라 현재도 쓰는지 확인이 필요하다.
6. 맛 표현의 허용 범위: 아래 "말투" 3번은 작성자 판단이다.

## 금지 사항

1. 효능, 건강 관련 주장.
2. 확인되지 않은 숫자와 "작성자 주장"으로 분류된 과거 수치.
3. 사고, 재난, 정치 화제에 붙이는 글.
4. 동의받지 않은 고객 리뷰와 문의 인용.
5. 유료 이미지 생성, 경품, 쿠폰 제안 (대표님 승인 전).
6. 얼굴이나 다른 업체 상표가 보이는 소재를 그대로 쓰는 구성.
7. 다른 사람이나 다른 브랜드를 조롱하는 문장.

## 말투

1. 짧은 문장. 한 문장에 내용 하나.
2. 설명보다 장면. "칼칼합니다"보다 "된장찌개에 한 스푼 넣는 장면".
3. 맛 표현은 "칼칼하다", "알싸하다" 같은 감각 묘사까지만 쓴다. "최고", "1등", 다른 제품보다 낫다는 비교는 쓰지 않는다. (작성자 판단)
4. 스레드는 혼잣말처럼 가볍게. 예: "첫눈 오면 찌개, 찌개 끓이면 한 숟갈. 순서 바꾸지 마세요"
5. 광고 대본은 등장인물이 반론을 대신 말하는 상황극이 잘 맞는다. 예: "고추 다진 걸 돈 주고 사? 내가 다지면 되지."

## 핵심 설득 재료

1. 기준점: 청양고추를 사서 직접 다지는 수고 (눈이 맵고 손이 간다).
2. 흔한 반론: "직접 다지면 된다", "비쌀 것 같다", "어디에 넣는지 모르겠다".
3. 빈틈을 묻는 질문: "국이 심심할 때 뭘 넣으세요?"
4. 쓰임새 장면: 된장찌개, 라면, 계란밥, 고기 쌈, 칼국수.
