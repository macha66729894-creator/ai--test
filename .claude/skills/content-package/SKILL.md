# 주제 하나로 전 채널 콘텐츠 패키지

입력은 주제 한 줄이다. 예: `/content-package 국이 심심할 때 한 숟갈`

제품과 목적이 없으면 묻지 않는다. 기본값(제품: 고추다짐이, 목적: 카페24 자사몰 유입)으로 진행하고, 결과 보고에 어떤 가정을 썼는지 적는다.

## 절대 규칙

1. 게시, 예약 게시, 광고 집행은 하지 않는다. 결과물은 초안이며 대표님 승인 전 단계다.
2. 확인되지 않은 사실과 숫자를 쓰지 않는다. 가격, 판매량, 기간은 `[ ]`로 비워둔다.
3. 이미지, 영상, 음성은 생성하지 않는다. 글과 구성안만 만든다.
4. 모든 결과물 끝에 출처를 남긴다. 사용한 Notion 페이지 링크, 심리 원리의 문헌, 그리고 근거 없이 직접 판단한 부분은 "작성자 판단"이라고 표시한다.

## 순서

### 1단계: 기준 읽기

같은 폴더의 세 파일을 먼저 읽는다.

- `brand-maekomchan.md`: 제품 사실, 말투, 금지 사항
- `rubric.md`: 합격 기준 채점표
- `formats.md`: 채널별 규격과 틀

주제와 관련된 과거 자료가 필요하면 Notion에서 찾는다. `brand-maekomchan.md`의 "참고 자료" 목록부터 본다.

### 2단계: 설계 한 장

초안을 쓰기 전에 아래 여섯 줄을 먼저 채운다. 모든 채널이 이 한 장을 공유한다.

1. 타깃이 지금 속으로 하는 말 한 문장
2. 타깃이 할 반론 3개 (예: "직접 다지면 되지", "비쌀 것 같은데")
3. 반론마다 보여줄 근거 (화면에 보이는 장면, 확인된 사실, 비교 기준점)
4. 지금 습관의 빈틈과, 바뀐 뒤의 모습
5. 핵심 메시지 한 줄
6. 시키고 싶은 행동 하나

### 3단계: 채널별 초안

`formats.md`의 틀대로 다섯 가지를 쓴다. 릴스 대본, 카드뉴스, 스레드 3안, 블로그, 뉴스레터.

### 4단계: 채점과 재작성

작성자 입장을 내려놓고 `rubric.md`로 채널별 점수를 매긴다. 처음 보는 사람이 읽는다고 생각하고 채점한다.

- 80점 이상이고 결격 사유가 없으면 합격.
- 미달이면 감점된 항목만 고쳐 다시 채점한다. 최대 2회.
- 2회 뒤에도 미달이면 "불합격"으로 표시하고 이유를 적는다. 점수를 올려 적지 않는다.

### 5단계: Notion 저장

합격한 패키지를 콘텐츠 캘린더(`collection://47f9d92c-5a22-417a-a20b-ad7429a5d7eb`)에 페이지 하나로 만든다.

- 제목: 주제
- 상태: `검토 대기`
- 채널: 포함된 채널 (인스타그램, 스레드, 블로그, 뉴스레터, 유튜브)
- 핵심 메시지: 설계 한 장의 5번
- 본문 순서: 설계 한 장, 채널별 초안, 채점표, 확인 필요 항목, 출처

불합격한 채널은 저장하지 않고 보고에만 적는다. Notion 저장이 실패하면 저장소의 `outputs/날짜-주제.md`에 같은 내용을 쓰고 실패했다고 알린다.

### 6단계: 보고

채팅에는 짧게 적는다.

1. Notion 페이지 링크
2. 채널별 점수표
3. 대표님이 정해야 할 것 (빈칸 수치, 확인 필요한 표현)
4. 사용한 가정
5. 출처
