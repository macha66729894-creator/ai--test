# 설치된 Claude 스킬

이 폴더의 스킬은 이 저장소로 Claude Code 세션을 열면 자동으로 불러옵니다.
명령어 없이 평소처럼 요청하면 맞는 스킬이 적용됩니다.

| 스킬 | 이런 요청에 작동 |
|---|---|
| `marketing-psychology` | 구매 심리, 인지편향, 설득 기법 분석 |
| `copywriting` | 랜딩·상세페이지 카피 작성과 수정 |
| `offers` | 오퍼 설계(가치 쌓기, 보너스, 보증, 희소성) |
| `pricing` | 가격과 요금제 구성 |
| `customer-research` | 고객 리뷰·인터뷰 분석, 페르소나 |
| `cro` | 페이지·폼 전환율 개선 |
